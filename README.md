# Daisy Days — Web Demo 🌼

**เปิดเล่นได้เลยในเบราว์เซอร์ ไม่ต้องติดตั้ง ไม่ต้องสมัครบัญชี**
👉 **https://duanganucha.github.io/daisydays-web/**

Daisy Days คือแอปบันทึกรอบเดือนและอาการที่ทำงาน **ออฟไลน์ 100%** — ข้อมูลทั้งหมดเก็บอยู่ในเครื่องคุณเท่านั้น ไม่มีการส่งขึ้นเซิร์ฟเวอร์ ไม่ต้องล็อกอิน

> Daisy Days is an offline-first period & symptom pattern tracker. All data stays on your device — no account, no server, no tracking.

## คุณสมบัติ / Features

- 📅 บันทึกรอบเดือน ประจำเดือน และอาการรายวัน
- 📊 ดูรูปแบบ (pattern) ของอาการย้อนหลัง
- 🔮 คาดการณ์รอบถัดไปจากข้อมูลของคุณเอง
- 📴 ทำงานออฟไลน์เต็มรูปแบบ — ไม่ต้องต่อเน็ต
- 🚫 ไม่เก็บข้อมูลขึ้นคลาวด์ ไม่มีบัญชีผู้ใช้

---

## ข้อมูลของคุณอยู่ที่ไหน? / Where is my data?

อยู่ใน **เครื่องของคุณ** (browser local storage) เท่านั้น

- ไม่มีเซิร์ฟเวอร์รับข้อมูล — repo นี้เป็นไฟล์ static ที่ GitHub Pages เสิร์ฟให้เฉย ๆ
- ถ้าล้างข้อมูลเบราว์เซอร์ ข้อมูลจะหายไปด้วย
- เดโมเว็บกับแอปบนมือถือ **ไม่ซิงก์กัน** เป็นข้อมูลแยกกัน
